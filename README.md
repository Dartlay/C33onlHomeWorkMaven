## 🌟 Основные возможности  

- 👨‍🎓 **Управление студентами**  
  - Добавление, редактирование, удаление  
  - Группировка по учебным группам  

- 📚 **Управление предметами**  
  - Создание и редактирование дисциплин  

- ⭐ **Система оценок**  
  - Выставление оценок (1-5 баллов)  
  

- 📊 **Dashboard**  
 (Было в планах , но по скольку я не использовал БД по типу Postman, то реолизовать нормальный конторль обновленных даных ( Счетчик ) у меня не вышло :3 )

- 📥 **Экспорт данных**  
  - Поддержка форматов JSON и TXT
