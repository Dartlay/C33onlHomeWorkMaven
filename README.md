Из-за ограничений среды разработки (**macOS + IntelliJ IDEA CE**) я не могу проверить логирование через встроенный терминал IDE.  

 Причины: 
1. Версия IntelliJ IDEA CE не поддерживает интеграцию с Tomcat.  
2. Установка неофициальных патчей (кряков) нежелательна из соображений безопасности (требует полного доступа к системе MacOs).  
3. Мне приходиться делать Ручной запуск через терминал

Ручной запуск через терминал

1. Сборка проекта: 
   ```bash
   mvn clean package
   ```
2. Переход в директорию с `.war`-файлом
3. Работа с Docker: 
   ```bash
   docker build -t <IMAGE_NAME> .
   docker run -d -p <PORT>:8080 <IMAGE_NAME>
   ```
   Для удобства я написал скрипт, автоматизирующий эти шаги.
